# Web Scraping Project

This is a basic web scraping project built using Python.

## Description
This project extracts quotes and author names from a website using web scraping techniques.

## Features
- Scrapes multiple pages (pagination)
- Extracts quote text and author
- Stores data in CSV format
- Clean and simple output

## Technologies Used
- Python
- Requests
- BeautifulSoup

## How to Run

1. Install dependencies:
   pip install requests beautifulsoup4

2. Run the script:
   python quotes_scraper.py

## Output
- Generates a CSV file (quotes.csv) containing extracted data
